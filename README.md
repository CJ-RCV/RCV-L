## ✦ عن RCV Launcher

**RCV Launcher** مشروع مفتوح المصدر هدفه تقديم تجربة Minecraft: Java Edition على هواتف Android بتصميم يحمل هوية مجتمع **RCV**، مع الحفاظ على محرك التشغيل والوظائف الأساسية من مشروع [Zalith Launcher 2](https://github.com/ZalithLauncher/ZalithLauncher2).

الهدف: واجهة واضحة، وصول سريع للإصدارات والسيرفر، وإعدادات تناسب الأجهزة المختلفة — بدون تشتيت أو خطوات معقّدة.

> **تنويه مهم:** هذا **Unofficial Modified Version** — إصدار غير رسمي معدّل من Zalith Launcher 2، وليس منتجاً رسمياً أو تابعاً لمطوريه أو لشركتي Mojang وMicrosoft.

## 🧑‍💻 للمطورين

هذا المستودع مبني على المصدر المفتوح لـ **Zalith Launcher 2**. يتطلب البناء JDK 21، وAndroid SDK/NDK الموافق لإعدادات Gradle.

```bash
git clone https://github.com/CJ-RCV/RCV-L.git
cd RCV-L
bash ./gradlew :ZalithLauncher:assembleDebug -Darch=arm64
```

**ملاحظة:** قد يحتاج البناء إلى تحميل مكتبات كبيرة وإعداد Android SDK. لا تستخدم APK غير مختبَر كتحديث مستقر.

### RCV Launcher — Minecraft Java on Android

RCV Launcher is a **community-built, unofficial modified version** of [Zalith Launcher 2](https://github.com/ZalithLauncher/ZalithLauncher2). Our aim is to make Minecraft Java on Android simpler with a fresh RCV identity, a cleaner home experience and convenient community links.

**What is included in the source**
- Upstream Minecraft Java engine, version management, touch controls and launcher settings.
- RCV Launcher name and independent Android application ID.
- New RCV Community home card with website and Twitch links.
- Arabic and English text for RCV elements.
- Accessible credits and GPL notices under Settings → About.

**What comes next:** unique icon and theme, server hub, performance presets, testing and official APK builds.
