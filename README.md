## Overview

**RCV Launcher** brings Minecraft Java to Android with a streamlined interface, quick access to the RCV community, and the flexibility to configure your game.

It's built on the open-source Zalith Launcher 2 engine. We are developing the RCV experience step by step, prioritizing usability, stability, and performance.

## Features

| | |
|:--|:--|
| **Minecraft Java on Android** | Launch Minecraft Java using the underlying Android-compatible launcher engine. |
| **Version management** | Browse, install, and organize Minecraft versions. |
| **Touch controls** | Configure controls for mobile gameplay. |
| **Graphics & performance** | Adjust launcher and game settings for your device. |
| **RCV Home** | A dedicated welcome section with fast access to the community and streams. |
| **Language support** | English and Arabic strings for RCV-specific sections. |

<sub>Core gameplay features come from the upstream launcher. RCV branding and community shortcuts have been added to the source; the APK is not yet tested.</sub>

## Download

The first **RCV Launcher APK** is not available yet.

Once a build passes testing, it will appear on the [Releases page](https://github.com/CJ-RCV/RCV-L/releases), together with its version number, installation instructions, and change log.

The download counter at the top automatically reflects GitHub Release asset downloads. It does **not** count repository visits or source ZIP downloads.
